# «Есть что показать» — пакет передачи дизайна в разработку

Версия пакета: 2026-10-05 · прототип v31 · дизайн-система «Точность» (с тёплым вторым актом).

## Как пользоваться

1. Распакуйте архив в корень репозитория (или в папку `design/` и перенесите `CLAUDE.md` в корень).
2. Откройте `reference/prototype/index.html` двойным кликом — это рабочий эталон сайта со всеми анимациями (на компьютере листайте колесом/стрелками, на телефоне — свайпом).
3. Запустите Claude Code в репозитории и дайте первый промпт из `docs/09_BUILD_PLAN.md`. `CLAUDE.md` он прочитает сам.

## Важно

- Кейсы — **обезличенные концепты**, не клиенты. Исходные PDF компаний в пакет не включены намеренно.
- Тексты частично черновые (помечены в `docs/06_CONTENT_RU.md`).
- Слова WebGL, AI, Engine, Claude, Higgsfield на сайте не появляются.
