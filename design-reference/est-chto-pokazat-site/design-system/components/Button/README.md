# Button

Кнопка-действие: прямоугольник 56px с подписью слева и стрелкой справа; одна основная кнопка на экран.

## Варианты

| Вариант | Класс | Когда |
|---|---|---|
| Основная | `.ecp-btn--primary` | Единственное целевое действие экрана: «Обсудить ваш бизнес», «Отправить». Заливка `inverse-bg`, текст `inverse-ink` |
| Вторичная | `.ecp-btn--secondary` | Быстрые переходы: «Посмотреть кейсы». Рамка `control-border`, текст `ink` |
| Текстовая | `.ecp-btn--text` | Внутри контента: «Как это было» в карточке кейса. Подчёркивание `line` → `accent` при наведении |
| Во всю ширину | `.ecp-btn--block` | На мобильном основная и вторичная всегда во всю ширину |

## Состояния

- Наведение: основная → `inverse-bg-hover`; вторичная → рамка `ink`; стрелка сдвигается на 4px (`duration-short`, `ease-precise`).
- Фокус: кольцо `focus` 2px со смещением 2px (`:focus-visible`).
- Недоступна (`disabled`): прозрачный фон, рамка `line`, текст `ink-faint`. Используется только для отправки формы до согласия.

## Правила

- Подпись — глагол о бизнесе клиента, а не о сайте: «Обсудить ваш бизнес», не «Заказать сайт», не «Оставить заявку».
- Стрелка — единственная иконка в кнопках; без иконок слева.
- Радиус `radius-1` (2px). Никаких пилюль и теней.
- Высота 56px (мобильный и десктоп), поле касания ≥44px у текстовой.
- Ссылка — `<a class="ecp-btn">`, действие формы — `<button>`.

Потребитель передаёт: подпись, `href` или `type`, вариант.
