# Navigation

Минимальная постоянная навигация: знак слева и ровно три якоря — «Кейсы», «Как мы работаем», «Обсудить»; на мобильном они спрятаны за кнопкой-плюсом.

## Анатомия

- `.ecp-nav` — шапка, поля `space-5` (мобильный) / `space-7` (десктоп от 900px).
- `.ecp-logo` — знак (см. Logo).
- `.ecp-nav__toggle` — кнопка 44×44 с плюсом; при `aria-expanded="true"` плюс поворачивается на 45° (крестик), `duration-short`, `ease-precise`. `aria-label` меняется: «Открыть меню» / «Закрыть меню».
- `.ecp-menu` — открытое меню на `bg-raised`: строки 64px+, разделены `line`, номер блока капителью (`ecp-index`) + название `t-h3`. Номер текущего блока — `accent` (`aria-current="true"`).
- `.ecp-navlink` — пункт десктопной шапки, 14px, подчёркивание `accent` при наведении.

## Поведение

- Шапка не прилипает, пока посетитель в первой половине: тишина важнее навигации. После поворота появляется компактная прилипающая шапка (тот же состав) — она нужна тем, кто пришёл после презентации и ищет кейсы и форму.
- Переход по якорю к кейсам пропускает поворот — это допустимо (решение Experience Concept).
- Меню открывается сдвигом вниз на 8px + прозрачность (`duration-short`); закрывается `ease-exit`. При уменьшении движения — только прозрачность.
- Esc закрывает меню, фокус возвращается на кнопку.

## Правила

- Только три пункта. Никаких «Услуг», «О нас», «Портфолио», телефона в шапке.
- Названия пунктов не меняем без решения: они повторяют три якоря из Experience Concept.

Потребитель передаёт: якоря секций и текущий блок.
