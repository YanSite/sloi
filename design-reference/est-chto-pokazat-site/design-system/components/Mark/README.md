# Mark

Отметка внимания: тонкое подчёркивание `accent` под одним словом — так внимательный эксперт показывает, что он заметил главное.

## Анатомия

- `.ecp-mark` — `<span>` вокруг слова или короткой группы слов; линия 1px `accent` с отступом 4px от базовой линии.
- В паре с ним часто стоит `.ecp-index` — номер блока капителью над высказыванием.

## Движение

Линия прорисовывается слева направо за `duration-base` (`ease-precise`) через 240ms после того, как строка появилась на экране: сначала посетитель читает, потом видит, что мы заметили. Технически: слово рендерится с `.ecp-mark .ecp-mark--pending`, класс `--pending` снимается, когда строка вошла в экран (переход уже задан в стиле). При уменьшении движения — линия сразу на месте.

## Правила

- Одна отметка на экран. Отмечается то, что уже есть у клиента («показать», «уже есть»), а не наши достоинства.
- Только подчёркивание: не выделение фоном, не обводка, не маркер, не цветной текст.
- Не на ссылках — у ссылок своя линия (`line` → `accent` при наведении).
- В проявленном мире `accent` светлее (`signal-blue-light`) — класс тот же.

Потребитель передаёт: слово для отметки.
