# CaseCard

Карточка кейса в блоке «Доказательство»: метка, изображение, название и три строки истории «было сильным → не было видно → проявили»; вся карточка — ссылка на страницу кейса.

## Анатомия

- `.ecp-case` — `<a>` на страницу кейса; верхняя волосяная линия `line`.
- `.ecp-case__meta` — «Кейс 01» (`ecp-caption`) и сфера бизнеса (`ecp-index`).
- `.ecp-case__media` — изображение 4:5, `radius-0`, подложка `bg-raised`. При наведении — увеличение до 1.02 за `duration-base`.
- `.ecp-case__title` — название бизнеса, `t-h3`.
- `.ecp-case__story` — три строки сеткой «метка 96px | текст», разделены `line`. Метки фиксированы: «Было сильным», «Не было видно», «Проявили». Текст `t-body-s`, `ink-muted`.
- `.ecp-case__more` — «Как это было» + стрелка; подчёркивание становится `accent` при наведении карточки.

## Правила

- Живёт в проявленном мире (`data-theme="revealed"`). Каждый кейс может нести свою атмосферу в изображении — но рамка карточки, типографика и метки одни: «разные миры, одна способность».
- Никаких цифр и результатов (заявки, выручка, рост) — подтверждённых данных нет.
- Стиль кейса не переносится на интерфейс агентства: цвета концептов (цветочный магазин, кафе-пекарня) остаются внутри изображения.
- Текст строк истории — по одному предложению, до 120 знаков.
- Материалы (изображения, формулировки) для концептов (цветочный магазин, кафе-пекарня) ещё не собраны — на превью заглушки в квадратных скобках.

Потребитель передаёт: `href`, номер, сферу, изображение с `alt`, название, три текста истории.
