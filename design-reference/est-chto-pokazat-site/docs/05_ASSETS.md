# 05 — Медиа: манифест

Все файлы — в `reference/prototype/media/`. При вёрстке перенести в `public/media/` (имена сохранить), сжать в AVIF/WebP с JPEG-фолбэком, отдать `srcset` (1x/2x). Итого ≈ 3.1 МБ в исходниках.

**Происхождение.** Фото улицы, руки с телефоном и заведения — сгенерированы для сайта (Higgsfield). Материалы кейсов — из концептов агентства для двух компаний, **обезличены** (логотипы, адреса, рейтинги убраны; на слайдах 1 и 12 пекарни вместо логотипа — «Тёплое печенье»). На слайде 9 пекарни и на слайдах цветов от стёртого логотипа может остаться еле заметный след — на стенах в перспективе не виден; при показе крупно — подчистить.
