# 07 — Проверки (обязательно после каждой правки вёрстки/анимаций)

## Правило 1 — нет щели у краёв кадра (особенно сверху)
Запуск (нужны Node + Playwright, Python + numpy + Pillow):
```bash
npm i -D playwright && npx playwright install chromium
pip install numpy pillow
node tools/qa/gapcheck.js 1440x900,1280x720,1920x1080,390x844,375x667,430x932 <путь к странице>
python3 tools/qa/gapcheck.py      # итог: «щелей 0» — иначе не готово
```
- Скрипт проходит все экраны 01→07 (включая первый свайп на 01), по два кадра на экран: через 0.5 с после прихода и после анимаций (~3 с). Для своего сайта поправьте в `gapcheck.js` способ перехода между экранами и URL.
- Щель = однотонная полоса у края по всей ширине, резко отличающаяся от картинки под ней. Кнопки у нижнего края — контент, не щель (детектор их пропускает).
- Известные причины: вертикальный сдвиг полноэкранного слоя (`translateY`) без запаса; параллакс за курсором; размытие (`blur`) у края без увеличения слоя; фото, которое начинается ниже верха экрана, на почти чёрном фоне.
- Профилактика: у каждого полноэкранного слоя запас `scale ≥ 1.06` (фото руки на десктопе — cover ×1.1); затемнения шире экрана (`inset: -22vh -6vw …`); никаких сдвигов больше запаса.

## Правило 2 — экран совпадает с корпусом телефона
- Поворот 04: сравнить кадры на 3.7 / 4.1 / 5.4 с — экран сайта точно в рамке телефона, без зазора и наезда.
- Сайт в телефоне и фото руки двигаются **одним transform** с **общей точкой опоры**; пока рука скрыта, она заранее встаёт в финальную позицию.
- Статус-бар и home indicator на всех телефонах: пропорции iPhone 15 Pro (см. `04_DESIGN_TOKENS.md`).

## Правило 3 — мобильные размеры
- На 375×667: ничего не налезает на нижнюю строку «Дальше» / счётчик; финал без наложений.
- На 04 моб.: телефон виден целиком между текстом и нижней строкой.
- Текст не перекрывается телефоном на 01–03.

## Правило 4 — без ожидания и без «лишних» жестов
- Смысл каждого экрана читается сразу; вступления кейсов пропускаются касанием/свайпом.
- Первый свайп на 01 меняет состояние кадра (свет гаснет), второй — листает.

## Правило 5 — бренд и данные
- Поиск по проекту не находит: `Flowerstim`, `Куки Луки`, `Эстетика цветов`, `Бутырск`, `WebGL`, `Three`, `AI`, `Claude`, `Higgsfield` в видимых текстах, alt, мета и именах файлов.
- Кейсы подписаны «Концепт», цифр нет.
