# 09 — План вёрстки с Claude Code (по шагам, с промптами)

Каждый шаг — отдельный PR/коммит. После каждого шага — проверки из `docs/07_QA.md` (команда `/qa`) и сравнение со снимками `reference/screens/` (команда `/screens`).

### Шаг 0 — каркас
> Прочитай CLAUDE.md и docs/. Создай проект на Vite + TypeScript без фреймворка (если в репозитории нет своего стека). Перенеси медиа из reference/prototype/media в public/media, подключи design-system/tokens.css, шрифты Geologica и Cormorant Garamond локально (woff2). Сделай пустую колоду из 8 экранов с навигацией (свайп, колесо с накоплением и блокировкой, клавиши, кнопка «Дальше», счётчик, меню, точки на десктопе) — поведение как в reference/prototype/index.html. Тексты из docs/06_CONTENT_RU.md.

### Шаг 1 — тихая половина (01–03)
> Сверстай экраны 01–03 по docs/02_SCREENS.md: слой film с состояниями street/hand/scroll/glow, рука с телефоном и HTML-лентой карточек, первый свайп на 01 (свет гаснет, цвет уходит), «ныряние» в телефон на 02 и 3D-поле карточек, подъём карточки со светом на 03. Тайминги — docs/03_MOTION.md. Проверь отсутствие щелей (/qa) на всех размерах.

### Шаг 2 — поворот (04)
> Сверстай поворот: клип-раскрытие из фото карточки, режим чертежа с SVG-линиями окон, каркас и сайт «Кофейня на углу» в телефоне, проявление руки и наезд камеры. Сайт и рука — общий transform и общая точка опоры. Сделай сцену отдельным модулем с интерфейсом play()/reset()/setFinal(), чтобы позже заменить её на версию на движке. Проверь совпадение экрана с корпусом на 3.7/4.1/5.4 с.

### Шаг 3 — проекты (05 ×2)
> Сверстай два экрана кейсов: вступление «макро → пролёт насквозь» с пропуском по касанию, коридор-выставку из слайдов (цветы 9, пекарня 12), CSS-телефон iPhone 15 Pro, экраны сайтов в телефоне кодом (цветы — страница с букетом и заголовком; пекарня — 3 кадра с «пролётом сквозь печенье»), историю из трёх строк сразу. Только обезличенные материалы (docs/05_ASSETS.md).

### Шаг 4 — 06, 07 и форма
> Сверстай «Как мы работаем» (шаги загораются по очереди), финал (резкая улица, тезисы, пульсирующая кнопка) и форму в нижней шторке с валидацией, сменой поля контакта по каналу, обязательным согласием 152-ФЗ. Отправку пока сделай заглушкой (console + состояние «Получили.»); текст подтверждения — заглушка [..].

### Шаг 5 — качество
> Добавь prefers-reduced-motion (fade 200 мс, финальные состояния), ленивую подгрузку медиа второй половины, AVIF/WebP + srcset, og-мета, фокус-кольца, aria для меню и формы. Прогони /qa на всех размерах, Lighthouse mobile (Perf ≥ 85, A11y ≥ 95). Сравни со снимками reference/screens и перечисли расхождения.

### Шаг 6 — деплой
> Подготовь статическую сборку и инструкцию деплоя (Vercel/Netlify/любой статический хостинг). Проверь, что в собранных файлах нет запрещённых слов (docs/07_QA.md, правило 5).
