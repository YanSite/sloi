# 03 — Движение: кривые, длительности, таймлайны

## Кривые
| Токен | Значение | Где |
|---|---|---|
| `--ease` (precise) | `cubic-bezier(0.2, 0, 0, 1)` | почти всё: появления, наезды, переходы |
| `--ease-turn` | `cubic-bezier(0.65, 0, 0.35, 1)` | клип-раскрытие поворота, сетка мира |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | уход экрана |
| «ныряние» | `cubic-bezier(0.55, 0, 0.75, 0.3)` | 01→02: рука улетает в камеру |
| «пролёт насквозь» | `cubic-bezier(0.6, 0, 0.85, 0.35)` | вступление кейса: макро в камеру |

## Базовые длительности
- Появление элемента `.a`: 720 мс, задержка 180 мс + 80 мс × `--i`.
- Заголовок по словам: 820 мс, 42 мс на слово.
- Уход экрана: 420 мс.
- Отметка (подчёркивание слова): 600 мс после 1100–1250 мс.
- Hover кнопки: стрелка сдвигается на 4px, 240 мс.
- «Меньше движения»: все переходы — fade 200 мс.

## 01 — первый свайп «онлайн»
| t | Событие |
|---|---|
| 0 | вторая строка → яркая (900 мс, задержка 500), первая → 0.32 |
| 0 | цвет уходит: улица/рука в ч/б и темнее (1300–1600 мс) |
| 0 / 220 / 440 / 660 мс | гаснут огни окон g1…g4 (по 700 мс) |
| 0 | телефон подъезжает (1400 мс, `--ease`) |
| 1700 мс | `.ready` |

## 02 / 03
- 01→02: рука `scale(2.6) translateY(-6%)` + fade 700 мс; поле карточек: `scale(1.25)→1` 1600 мс (задержка 150), fade 900 мс (задержка 250).
- Поле плывёт: `translateY(0 → -244px)` 14 с linear, бесконечно.
- 03: карточка `hlift` 1500 мс; свет — 1200 мс (задержка 500); лучи — fade 1600 мс (задержка 900) + вращение 70 с; блик по карточке 1500 мс (задержка 1100); «дыхание» ±8px 6 с.

## 04 — поворот (первый проход)
| t, мс | Событие |
|---|---|
| 0 | клип от прямоугольника фото карточки до полного экрана, 1500 мс `--ease-turn`; внутри улица в режиме чертежа |
| 300 + 60×k | линии чертежа рисуются (1300 мс каждая) |
| 2100 | в телефоне каркас (прямоугольники, 700 мс, сдвиг 80 мс), чертёж гаснет (700 мс) |
| 3000 | каркас заполняется сайтом (700 мс), через 1.6 с начинается медленная прокрутка сайта (9 с туда-обратно) |
| 3200 | текст после поворота |
| 3800 | рука проявляется (1100 мс) + наезд камеры на продукт (1800 мс, `--ease`), фон уходит в тень |
| 4200 | `.ready` |
Блокировка навигации на первом проходе — 2000 мс. Пока рука скрыта (0–3800), она заранее и без анимации встаёт в финальную позицию — иначе при проявлении экран и корпус разъедутся.

## 05 — вступление кейса
| t, мс | Событие |
|---|---|
| 0 | макро на весь экран, отъезд `scale(1.16→1.02)` 1300 мс; подпись 700 мс (задержка 150); название — подъём + снятие размытия 1000 мс (задержка 250) |
| 1150 | пролёт: макро `scale(3.6)` + blur 18px, 1000 мс; макро гаснет (700 мс, задержка 380); витрина собирается: дальний план 1500 мс, телефон 1300 мс, передний план 1500 мс |
| 1150 + 350…570 | строки истории (волна 110 мс) |
| 2950 | `.ready` |
Касание/свайп во время 0–1150 → сразу шаг «пролёт».

Экран пекарни в телефоне: цикл 9 с, три кадра со сдвигом 3 с (точнее 2.28 с перекрытия): вход 0–8% (из `scale(.86)` с размытием), держится до 30%, уход 30–37% (`scale(1.9)`, blur 7px). Фон вокруг затемняется синхронно с чёрным кадром.

## 06
Шаги загораются: 900, 1700, 2500 мс; линия над шагом прорисовывается 900 мс.

## Правила
- Каждый эффект несёт смысл; ничего не движется «просто так».
- Самое сильное событие сайта — поворот. Остальные экраны не должны его перекрикивать.
- Пользователь не ждёт: смысл экрана читается сразу, длинное — пропускается.
- Без параллакса за курсором. Без вертикального сдвига полноэкранных слоёв без запаса.
