### 1.4 Поверхности, границы, тени

- Углы без скругления. Карточек нет.
- Плашки: `#FBF8F2`, padding 4–9px, без рамки.
- Промокод: hero — подчёркивание `1px dashed #1F1B18`; финал — рамка `1px dashed`, на hover `solid`.
- Выноски S04: точка 7px + линия 44×1px + mono-плашка.
- Тени: box-shadow не используется. Вместо теней:

  - боковая вуаль `linear-gradient(90deg, .9 → .72 @34% → 0 @62%)`;
  - hero-вуаль `linear-gradient(0deg, .94 → .8 @60% → 0)`;
  - финальная вуаль `radial-gradient(ellipse 60% 55%, .94 → .82 @55% → .55)`.

### 1.5 Image treatment и свет (post-процесс)

Один полноэкранный шейдер поверх всех сцен:

- **Grain:** шум ±0.035, меняется каждый кадр. Выключается prop `grain`.
- **Vignette:** яркость ×0.965 к краям (`smoothstep(.3, 1.1, r)`).
- **Blur:** 32 сэмпла по золотому углу, радиус в px × dpr. Используется для intro focus pull и переходов.
- **Exposure:** `exp2(expo)`, вспышка до +0.12 в переходе W2.
- Фото: тёплый дневной свет, ivory/champagne/blush/sage, без тёмных фонов. Промпты — `media/PROMPTS-S01-S04.md`.
- Color management three.js выключен (`ColorManagement.enabled = false`, `LinearSRGBColorSpace` на выходе): текстуры выводятся без конвертации. Это часть утверждённого вида.

### 1.6 Иерархия

3D-заголовок → серифный заголовок блока → body → mono-лейбл. Primary CTA — всегда тёмная плашка `#1F1B18` с mono-текстом. Вторичные ссылки — mono с подчёркиванием 1px.

## 2. Навигация: beats (snap scroll)

Прогресс `g` (0…1010). Сцены: `p1 = g/180`, `p2 = (g−180)/220`, `p3 = (g−400)/320`, `p4 = (g−720)/240`.

| Beat | g | Кадр |
|---|---|---|
| 1 | 0 | S01 Hero |
| 2 | 215 | Макро розы + блок 01 |
| 3 | 377 | S02 отъезд + блок 02 |
| 4 | 400 + 320·pc(z = −3.4) | S03 «Свет — первый материал.» |
| 5 | 400 + 320·pc(z = −9.6) | S03 «Остальное — руками.» |
| 6 | 690 | S03 рама № 06 |
| 7 | 770 | S04 объект целиком + выноски + intro |
| 8 | 842 | S04 stop 2 + блок 03 доставка |
| 9 | 936 | S04 stop 3 + уход за цветами |
| 10 | 1010 | Финал «Наш магазин» |

`pc(z)` — параметр на кривой камеры S03, ближайший к заданному z (поиск по 400 сэмплам).

**Ввод (обязательно 1:1):**

- **Wheel / трекпад:** дельты накапливаются, `deltaY + 0.3·deltaX`. Порог |acc| > 28 → один beat. Если между событиями пауза > 180 ms, накопитель сбрасывается. После шага ввод заблокирован; блок снимается, когда пауза > 180 ms и прошло > 450 ms, или в любом случае через 1700 ms (гасит инерцию трекпада).
- **Touch:** вертикальный свайп > 42px → один beat. Нативная прокрутка запрещена (`touchmove preventDefault`).
- **Клавиши:** ↓ / PageDown / Space — вперёд; ↑ / PageUp — назад; Home / End.
- **Твин:** `easeInOutCubic`, длительность `min(3000, 1500 + |Δg|·7)` ms. Новый шаг принимается только после 70 % текущего твина.
- `snapScroll = false` → обычный скролл: `g = scrollY / innerHeight · 100`, догоняние с коэффициентом 0.055 за кадр. Высоты секций: 180 / 220 / 320 / 240 / 100 vh.

## 3. Сцены

### S01 · Aperture (g 0–160)

- **Назначение:** первое впечатление и оффер. Букет как арт-объект в пространстве.
- **Composition (editorial spread):** букет в арке по центру, ничем не перекрыт.
  - 3D-плоскости в глубину:
    1. стена `S01_BG` (z −6);
    2. тень и букет `S01_BOUQUET` (z −2.95);
    3. передний план `S01_FOREGROUND` (z −0.6);
    4. поверх — 3D-заголовок «Эстетика / *цветов*» (z −2.0) и halo-дымка за ним (`blob #FAF6EF α .6`, 1.5 × ширина, 1.8 × высота заголовка).
  - renderOrder заголовка 100001, halo 100000 — выше переднего плана: лепесток не перекрывает буквы.
  - **Позиция заголовка** считается в `resize()` от фрустума стартовой камеры на глубине заголовка: `halfH = (5F + 2)·tan 19°`, `halfW = halfH·aspect`.
    - Левый край — поле `clamp(18px, 4vw, 64px)`, переведённое в мировые единицы.
    - Низ — `max(11vh, 100px)`, на mobile 262px; поправка −10 % высоты текстуры на нижний отступ canvas.
    - Ширина — `min(3.3, halfW·0.78)`; на mobile (aspect < 0.9) — 90 % ширины кадра за вычетом полей.
  - **DOM:**
    - шапка: слева «Магазин цветов · Москва», справа «Открыто до 00:00» + CTA «Выбрать букет →».
    - колонка справа внизу: ширина `min(272px, 100vw − 2·поле)`, низ совпадает с заголовком (`max(11vh,100px)`). Сверху вниз:
      - серифная строка «Авторские букеты с круглосуточной доставкой *по Москве*»;
      - линия 1px;
      - «★ 5,0 · 192 оценки»;
      - «Фото букета перед отправкой»;
      - промокод «−10% по промокоду ОСЕНЬ26» (dashed underline, по клику копирует код).
      
      Под колонкой локальная радиальная подложка: padding 44px, `rgba(250,246,239,.88 → .62 → 0)`.
    - «Листайте» + вертикальная линия 18px — по центру, `bottom 58px`.
- **Camera:** Perspective, FOV 38 → 26.
  - Старт: `(0, 0.7, 5·F + (1−intro)·0.5)`, lookAt `(0, 0.7, −3)`.
  - Въезд `dol = ss(0.04, 1, p1)` к `hero = (0.35, 1.05)`, z → `hero.z + 1.05`, кривая `dol^0.85`.
- **Intro:** `intro = ss(0, 2.6 s)`. Камера подъезжает на 0.5 wu, blur `(1 − intro)·9 px` (focus pull).
- **Cursor:** смещение камеры `gx·0.4`, `gy·0.24`, затухает при въезде (`gaze = 1 − dol·0.92`), сглаживание 0.06/кадр.
- **Breath:** FOV ±0.4 %, период 14 s.
- **Fade по глубине:** заголовок и передний план гаснут, когда камера подходит к ним ближе чем на 0.15–1.05 wu.
- **Тайминг DOM:**
  - «Магазин цветов · Москва»: 2.4–3.6 s, уходит на g 60–140;
  - CTA в шапке: 2.4–3.6 s, дальше виден всегда;
  - hero-полоса: 2.8–4.2 s, уходит на g 4–36;
  - «Листайте»: 4.2–5.4 s, уходит на g 2–14;
  - логотип в шапке: g 150–190.
- **Transition → S02 (W2, petal-through), g 160–205:** шейдерная маска-«лепесток».
  - Фронт идёт от центра по fbm-«прожилкам» (порог `1.35 − mix·2.1`, мягкость ±0.12).
  - Радиальное смещение UV `disp 0.1`, blur до 3.2 px и вспышка экспозиции +0.12 (обе по `sin(π·m)`).
  - В S01 камера в этот момент у центральной розы; S02 начинается с макро той же розы (`S02_MACRO`).

### S03 · Exhibition (g 400–720)

- **Назначение:** виртуальная выставка = навигация по каталогу. 6 рам, каждая — раздел flowerstim.ru.
- **Composition:** рамы в тумане `Fog(#F6F2EA, 3, 21)` (позиции и повороты — `ASSET-MANIFEST.md`). Между рамами висят 3D-фразы «Свет — первый *материал.*» (z −7) и «Остальное — *руками.*» (z −15.2).
- **Camera:** FOV 45. CatmullRom-путь `[0,0,2.3] → [0.6,0.1,−1.8] → [−0.4,0,−6.4] → [0.5,0.2,−11] → [−0.3,0.05,−15.6] → [0,−0.12,−19.6]`.
  - На mobile (aspect < 1) z +1.2.
  - Взгляд на точку пути +0.08 вперёд; на последних 20 % пути смещается к раме 06. При `pc < 0.03` камера смотрит прямо (0, 0, −1).

- **Click / tap:** движение < 10px и < 500 ms → в новой вкладке открывается раздел каталога с UTM `utm_content=s03_<slug>`. Клик по `a` / `button` игнорируется.

- **Transition → S04, g 700–738:** `disp 0.03`, blur до 2.2 px. Рама 06 и букет S04 — один ассет, стык бесшовный.

## 5. Reduced motion (`prefers-reduced-motion: reduce`)

Реализовано в прототипе и обязательно:

- твин beats отключён, `g` переходит сразу;
- intro = 1: нет focus pull и подъезда, DOM сразу видим;
- cursor-камера отключена, breath = 0;
- лупа открывается без сглаживания.

Сами переходы-шейдеры идут по `g`, поэтому при мгновенном переходе они не проигрываются.

## 6. Performance-параметры прототипа

- DPR: ≤ 2 на desktop, ≤ 1.5 на coarse pointer.
- Render targets: 2 полноэкранных (A / B) + 512² для лупы.
- Одна сцена в кадре; в переходе две.
- Анизотропия текстур 8.

## 7. Mobile (как реализовано)

- **F-фактор:** `F = 1 + (1 − aspect)·1.1` при aspect < 1. Умножает дистанции камер S01 (старт), S02 (финал отъезда) и S04 (все стопы), чтобы композиция влезала в портрет.
- **S03:** камера на +1.2 по z при aspect < 1.
- **Заголовок S01:** при aspect < 0.9 двухстрочный вариант `S01_TITLE_NARROW` шириной 3.4 wu.
- **Ввод:** вертикальный свайп > 42px = beat. Hover в S03 отключён, работает тап по раме. Лупа — долгое нажатие, круг 90px над пальцем.
- **DOM:** все размеры через `clamp` / `min`, ряды фактов и CTA переносятся (`flex-wrap`), контакты — `auto-fit` grid.
- **Кропы:** отдельных mobile-кропов нет, кадрирует камера.
